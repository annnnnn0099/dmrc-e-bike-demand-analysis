# dmrc-e-bike-demand-analysis
# 🚲 DMRC E-Bike Utilization Analysis

# 📌 Overview

This project analyzes the underutilization of rental e-bikes deployed near Delhi Metro stations. Using data-driven techniques and machine learning (Random Forest), the study identifies key factors affecting demand and proposes strategies to improve last-mile connectivity.

---

# 🎯 Objective

* Identify factors affecting e-bike usage
* Analyze demand patterns across time, weather, and location
* Optimize deployment strategy for improved utilization

---

# 📊 Dataset Features

* Footfall (metro ridership)
* Temperature, humidity, weather conditions
* Working day / holiday
* Seasonal variations
* Time (hour-based usage patterns)

---

# ⚙️ Tools & Technologies

* Python (Pandas, NumPy, Scikit-learn)
* Data Visualization (Matplotlib, Seaborn)
* Machine Learning (Random Forest)

---

# 📈 Key Insights

* Demand decreases significantly during high temperature and humidity
* Higher usage observed during working days vs holidays
* Poor app usability and bike availability visibility affect adoption
* Competition from e-rickshaws reduces usage

---

# 🤖 Model Performance

* Random Forest Accuracy:

  * Temperature prediction: **85.12%**
  * Holiday prediction: **97.25%**

---

# 💡 Recommendations

* Optimize bike placement using footfall and demand clustering
* Introduce dynamic pricing during peak hours
* Improve app UX for real-time availability tracking
* Enhance infrastructure and awareness near metro stations

---

# 📌 Future Scope

* Integrate real-time data for demand forecasting
* Use advanced models (XGBoost, Time Series)
* Develop interactive dashboards (Power BI/Tableau)

---

# 🚀 Conclusion

This project demonstrates how data analytics and machine learning can improve urban mobility solutions and enhance last-mile connectivity efficiency.
